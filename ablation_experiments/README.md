# 独立消融实验平台

本目录用于“面向陪伴场景的情感支持对话系统设计与实现”的 D、V、S 三层消融实验。所有样本、运行记录、GPT 评审和汇总结果均保存在本目录，且不读取或写入项目中的 `exp/`。

目录约定：

- `configs/` 保存分组配置矩阵和运行环境示例。
- `datasets/` 保存新建的对话与语音样本。
- `scripts/` 保存实验执行和结果处理脚本。
- `raw/` 只追加逐请求原始记录。
- `results/` 保存聚合指标和论文表格。

使用前复制 `configs/runtime.example.yaml` 为本机运行配置，并通过环境变量提供数据库口令和 GPT 密钥。运行配置不得提交到版本库。
